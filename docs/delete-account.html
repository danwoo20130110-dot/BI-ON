BI:ON 계정 및 데이터 삭제

BI:ON(개발자: 【운영자 이름】) 계정과 관련 데이터를 삭제하는 방법입니다.

앱에서 바로 삭제하기

  1. BI:ON 앱을 열고 아래쪽 프로필 탭을 누릅니다.
  2. 프로필 설정으로 들어갑니다.
  3. 맨 아래 회원 탈퇴를 누르고, 확인 창에서 탈퇴를 누릅니다.

탈퇴하면 즉시 삭제되며 되돌릴 수 없습니다.

앱을 쓸 수 없는 경우

가입한 이메일 주소에서 【문의 이메일】로 "BI:ON 계정 삭제 요청" 메일을 보내 주세요. 본인 확인 후 7일 이내에 삭제하고 결과를 알려 드립니다.

삭제되는 데이터

  • 계정 정보: 이메일 주소, 비밀번호
  • 프로필: 닉네임, 학교, 학년, 한 줄 소개, 프로필 사진
  • 모든 라이딩 기록(경로 위치, 거리, 시간, 속력 등)과 땅(영역), 랭킹 기록
  • 실시간 라이딩 위치 기록

보관되는 데이터

삭제 후 따로 보관하는 데이터는 없습니다. 【법령상 보존해야 하는 기록이 생기면 항목과 기간을 기재】
