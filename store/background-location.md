# 백그라운드 위치·포그라운드 서비스 신고 자료 (초안)

Play 콘솔 > 앱 콘텐츠 > 민감한 앱 권한 > 위치 권한, 그리고 포그라운드 서비스 권한(위치) 신고에 사용.

## 백그라운드 위치를 쓰는 기능
라이딩 경로 기록

## 설명 (신고서에 붙여 넣기)
BI:ON은 자전거 라이딩 경로를 기록하고, 달린 길을 지도 위 영역(땅)으로 바꾸는 앱입니다. 라이더는 주행 중 휴대폰을 주머니나 거치대에 두고 화면을 끄는 경우가 대부분이므로, 화면이 꺼진 동안에도 위치를 받아야 경로가 끊기지 않고 실제로 달린 길이 정확히 기록됩니다. 위치 수집은 사용자가 [시작하기]를 눌러 라이딩을 시작한 순간부터 [라이딩 종료]를 누를 때까지만 이루어지며, 그동안 "BI:ON 라이딩 기록 중" 알림이 계속 표시됩니다. 라이딩을 끝내면 즉시 위치 수집과 포그라운드 서비스를 중지합니다. 권한을 요청하기 전에 앱 안에서 수집 목적을 먼저 안내하고 동의를 받습니다.

## 포그라운드 서비스 유형
location (FOREGROUND_SERVICE_LOCATION) — 사용자가 시작한 라이딩 기록. 사용자가 직접 종료할 때까지 실행.

## 시연 영상 대본 (30~60초, 유튜브 일부 공개로 올리고 링크 제출)
1. 앱 홈 화면에서 [시작하기]를 누른다.
2. "화면이 꺼져도 기록할까요?" 안내창 → [계속]
3. 위치 권한 화면에서 "항상 허용"을 고르고 앱으로 돌아온다.
4. 상단 알림창을 내려 "BI:ON 라이딩 기록 중" 알림을 보여 준다.
5. 화면을 끄고 이동한다(또는 에뮬레이터에서 위치를 옮긴다).
6. 화면을 켜서 꺼져 있던 동안의 경로가 지도에 이어져 있는 것을 보여 준다.
7. [라이딩 종료] → 알림이 사라지는 것을 보여 준다.

## 심사관 안내 (앱 접근 권한 항목)
- 테스트 계정: 【심사용 이메일】 / 【비밀번호】 (출시 전 새 비밀번호로 바꿀 것)
- 홈 → [시작하기] 로 라이딩 시작, [라이딩 종료]로 끝냄
- 실시간 라이딩·땅따먹기는 실제 이동이 필요해, 가짜 위치 앱이나 에뮬레이터 위치 이동으로 확인 가능
